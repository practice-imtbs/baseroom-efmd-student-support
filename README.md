# baseroom-efmd-student-support

Base Room EFMD : accompagnement à la réussite étudiante / Student success support, bilan 2025-2026 (page protégée par mot de passe)

Page unique en français et en anglais (boutons FR / EN), préparée par le service PracTice d'IMT Business School avec le service Inscriptions et Accompagnement à la réussite étudiante, pour le dossier d'accréditation EFMD. Données agrégées et anonymisées.
Le contenu est chiffré (AES-256-GCM) : il faut le mot de passe fourni par l'équipe pour l'ouvrir.
